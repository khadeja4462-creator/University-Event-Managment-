# UniEvents — Week 1 starter

A static HTML + CSS + Bootstrap prototype for the University Event Management project.

## Run
Open `index.html` in a browser. Bootstrap is loaded from the CDN, so an internet connection is needed for Bootstrap styling and the responsive navbar.

## Included in Week 1
- GitHub-ready folder structure: `css/`, `js/`, `images/`
- Bootstrap navbar, grid, cards, badges, and forms
- Shared orange theme in `css/style.css`
- Pages: Home, Events, Event Details, Register, Login, Organizer, Admin, About
- `js/events.js`: 10 sample events
- `js/halls.js`: sample halls and capacities

## Important
This is a Week 1 front-end structure. Forms and dashboard controls are visual prototypes and do not save or submit data yet. Search/filtering, login logic, approvals, and localStorage belong to later implementation work.
